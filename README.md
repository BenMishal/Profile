# Ben Mishal — Portfolio

A lightweight, accessible single-page portfolio for Ben Mishal B S, hosted with GitHub Pages.

## What is included

- Responsive navigation with keyboard support
- Verified professional experience, education, credentials and project evidence
- Search and social-sharing metadata, structured data, sitemap and robots directives
- Motion that respects the visitor's reduced-motion preference
- No framework or build step; the site runs directly from `index.html`

## Local preview

Open `index.html` in a browser or serve the repository with any static file server.

## Validation

The repository includes a small standard-library Python check that verifies required metadata, navigation targets, duplicate IDs and referenced local assets. GitHub Actions runs it automatically for pull requests and pushes to `main`.

## Content policy

Professional outcomes are based on verified CV evidence. Academic and personal projects are explicitly labeled so they are not presented as client delivery.
